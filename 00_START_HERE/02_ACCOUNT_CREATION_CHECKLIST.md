# Account Creation Checklist

Use one owner identity/email where practical, but **never reuse passwords**.

## Security baseline
- Password manager: Bitwarden, 1Password, or equivalent.
- Unique 20+ character generated password per service.
- MFA / passkey wherever available.
- Store recovery codes offline.
- Never paste master passwords into NEEWA.
- Never commit API keys.
