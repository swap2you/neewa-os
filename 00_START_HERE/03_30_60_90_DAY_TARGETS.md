# 30 / 60 / 90 Day Targets

## Day 0–30 — Operational NEEWA
Goal: reliable orchestration, not revenue optimization.

Deliverables:
- always-on cloud NEEWA;
- private edge connection;
- text + voice interaction;
- structured memory;
- model gateway with budgets/fallbacks;
- Council, Governor, Done Gate;
- one real Wani/Bhava workflow;
- one real coding workflow;
- daily executive brief;
- disaster recovery tested;
- cost telemetry.

Exit criterion:
NEEWA completes a real bounded task end-to-end without manual prompt copying.

## Day 31–60 — Portfolio onboarding
- Wani production;
- Bhava implementation/review/UAT;
- Aarohan revenue/services pipeline;
- selected personal automation;
- local/offline model benchmarking;
- GPU/media workflow proof-of-concept;
- subscription utilization dashboard.

Exit criterion:
At least 3 projects can be managed through the same operating standard.

## Day 61–90 — Self-funding test
- productized service offers;
- lead/research pipeline;
- content/media experiments;
- opportunity scoring;
- measured revenue attribution;
- subscription keep/downgrade/cancel recommendation.

Target:
At least $300/month attributable revenue or equivalent recurring savings by the end of the proving period.

This is a target, not a guarantee. NEEWA must report probability and blockers honestly.
