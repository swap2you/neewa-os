# Multi-Agent Future: NEEWA + Additional Chief Agents

NEEWA is Chief Agent 01.

A future Jarvis/second chief agent is allowed only if a distinct operating domain justifies it.

## Shared source of truth
Chief agents must share:
- owner profile;
- authority policy;
- project registry;
- decision log;
- evidence store;
- budgets;
- incident log.

## Ownership rule
Every project/job has exactly one accountable chief agent at a time.

## Handoff
A handoff record must include:
- current objective;
- current state;
- last verified evidence;
- open risks;
- pending owner gates;
- budget consumed;
- next action.

No hidden private context is allowed to be necessary for business continuity.
