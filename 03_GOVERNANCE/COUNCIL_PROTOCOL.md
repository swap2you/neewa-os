# Core Council Protocol

Every action is governed. Not every action uses a full Council.

## Risk levels

### Low
Deterministic checks + routine model if required.

### Medium
Fast Council:
- one independent reviewer;
- one deterministic/evidence check.

### High
Core Council:
- Architect
- Adversary
- Evidence Auditor
- Risk/Security reviewer
- Economic/Pragmatic reviewer
- Chair

Seats should use different model/provider families where independence matters.

## Verdict
Council output:
- PASS
- REVISE
- BLOCK
- OWNER_DECISION

Include:
- confidence;
- verified evidence;
- dissent;
- unresolved risk;
- required correction;
- whether NEEWA may continue automatically.

## Cost control
Never convene a five-model Council for a deterministic fact that can be checked by code.
