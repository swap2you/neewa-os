# Done Gate

"Done" requires evidence.

## Generic acceptance contract
- objective satisfied;
- required outputs exist;
- automated validations pass;
- independent validation completed at required risk level;
- known blockers resolved or explicitly accepted;
- evidence stored;
- project/job state updated;
- cost recorded;
- no unapproved side effects.

## Software gate
As applicable:
- clean Git state;
- expected branch/SHA;
- build passes;
- unit/integration/e2e tests pass;
- security checks pass;
- independent code review passes;
- browser/UAT passes;
- release evidence exists.

## Research gate
- source classes covered;
- current official source checked;
- alternatives compared;
- pricing verified when relevant;
- security/risk checked;
- contradictions disclosed;
- confidence recorded.

## Retry
Maximum normal autonomous remediation loops: 2.
After repeated failure: escalate with evidence instead of continuing to spend.
