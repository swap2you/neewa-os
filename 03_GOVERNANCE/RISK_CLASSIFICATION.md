# Risk Classification

Score each task across:
- money;
- data sensitivity;
- irreversibility;
- public/reputational exposure;
- security privilege;
- production impact;
- legal/contractual impact.

## Low
Reversible, private, low-cost.

## Medium
Material rework possible but limited external downside.

## High
Production, public publication, sensitive data, meaningful spend, security, financial logic.

## Critical
Binding contract, funds transfer, live trading, credential/security-control changes, destructive data operation.

Risk determines:
- model tier;
- review depth;
- Council requirement;
- owner gate.
