# Documentation Standard

For every project:
- `PROJECT.md` — purpose, outcomes, boundaries;
- `STATUS.md` — current verified state;
- `DECISIONS.md` — major decisions;
- `RUNBOOK.md` — how to operate/recover;
- `evidence/` — validation artifacts;
- `jobs/` — job records.

Documentation must state:
- who/what performed the work;
- model/provider where relevant;
- exact version/commit/runtime;
- what was validated;
- what was not validated;
- cost and major external dependencies.

No fabricated PASS states.
