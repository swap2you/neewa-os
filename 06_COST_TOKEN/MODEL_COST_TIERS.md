# Model Cost Tiers

## Tier 0 — deterministic
No LLM.
Examples: tests, grep, hashes, ffmpeg, schema validation.

## Tier 1 — local / very cheap
Qwen/Gemma/local or Luna.
Examples: extraction, tagging, summarization.

## Tier 2 — balanced
Terra/equivalent.
Examples: ordinary analysis and implementation planning.

## Tier 3 — premium
GPT-5.6 Sol High.
Examples: owner strategy, difficult synthesis, Council chair.

## Tier 4 — exceptional
GPT-6 Astra.
Requires explicit escalation reason and budget check.

Track success rate by task type so routing improves from evidence.
