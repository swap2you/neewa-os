# Setup Prerequisites

Owner should have:
- primary email account secured with MFA;
- password manager;
- GitHub account;
- SSH client;
- modern browser;
- admin access to personal ThinkPad;
- ability to create billing accounts.

Do not use employer accounts/equipment for NEEWA infrastructure.

Before installing:
- backup critical personal files;
- create Windows restore point if appropriate;
- do not delete/move developer tools until the PC audit is reviewed.
