# Step 1 — Create / Confirm Accounts

Recommended order:
1. password manager;
2. GitHub/private repository;
3. AWS;
4. Tailscale;
5. OpenAI Platform;
6. Nous Portal;
7. OpenRouter;
8. Langfuse;
9. RunPod.

Use the same owner email where desired.

Use a unique password and MFA for each service.

Create a local offline record containing:
- account email;
- service URL;
- recovery-code location;
- billing plan;
- renewal date.

Do not store passwords or secret keys in this repository.
