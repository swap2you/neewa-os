# Step 12 — NEEWA-EDGE-01

Before edge onboarding:
- complete PC inventory;
- move/archive safe cold data;
- keep critical developer tools;
- do not indiscriminately uninstall.

Install/configure:
- Tailscale;
- Git;
- OpenHands Agent Canvas;
- Codex;
- Claude Code;
- Gemini CLI;
- existing Cursor;
- Docker/local tools as required.

Security:
- NEEWA gets approved workspace access, not total arbitrary Windows access;
- no employer devices;
- no employer credentials;
- sensitive personal folders excluded unless explicitly mounted.

Test:
- NEEWA creates a bounded job;
- edge worker receives it;
- worker returns evidence;
- NEEWA does not require manual prompt copy/paste.
