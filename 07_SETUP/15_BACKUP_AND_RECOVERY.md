# Step 15 — Backup / Recovery Test

Before real project onboarding:
- commit all config/docs to private Git;
- snapshot NEEWA-Core;
- back up durable runtime state;
- export provider/account inventory without secret values;
- record exact versions.

Perform a tabletop recovery:
"If NEEWA-Core disappears today, what is required to rebuild?"

Recovery must not depend on memory of manual steps.
